One line of awkward small talk a robot says to another while riding an elevator together: 214 shared rides, 213 rehearsed greetings, and the line lands on a bare "Hi."

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints it. Pure standard library, deterministic: two runs produce byte-identical output.
